How the portal works

Every project website is an HTML file in that project's GitHub repo, published with GitHub Pages. The portal loads it into a popup window at 95% of the screen, so each site is one tap away and you never leave this page.

Step 01

One file at the root

This splash page is what opens at jordanalbiar.github.io. It is the only link you ever need to share.

Step 02

Websites live in their repos

Each project's website is added to its own GitHub repo as HTML and served by GitHub Pages, the way the Nova Bot website was added to the nova-bot repo.

Step 03

Open in the popup

Tap a card and the portal loads that repo's website into a popup at 95% of the screen. Close the popup and you are right back at the portal.
